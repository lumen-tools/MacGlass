Imported shaders now work exactly as in ShaderGlass:

- Shader > Import custom... no longer copies anything. The `.slangp` or `.slang` is loaded from where it is.
- Shader > Recent imports remembers the last 20 imported files; an entry that can no longer be loaded is removed. Profiles store the path.
- In the shader browser, the third folder is called **Imported** (as in ShaderGlass) and lists the shaders imported in this session.

**Update from older versions:** the folder `~/Library/Application Support/MacGlass/Custom_Shader` used by MacGlass 0.1.0–0.1.8 is moved to the Trash on the first start (nothing is deleted for good), and settings that pointed into it are cleared – a profile or last shader from that folder falls back to the default shader. Import the original files again if you still need them.
