- Fix: no more repeated permission dialogs. 0.1.4 re-checked Screen Recording access every few seconds, which made macOS ask again and again. MacGlass now tries once at start; if access is missing, the window shows a hint with "Open System Settings" and "Try Again" and never asks on its own.

**One-time step from 0.1.3 or older:** since 0.1.4 the app has a stable signature, so the existing permission entry belongs to the old version. In System Settings > Privacy & Security > Screen & System Audio Recording, remove MacGlass with "−", add `/Applications/MacGlass.app` again with "+", then reopen MacGlass. Alternatively run `tccutil reset ScreenCapture io.github.lumen-tools.MacGlass` in Terminal and allow it once more. Future updates keep the permission.
