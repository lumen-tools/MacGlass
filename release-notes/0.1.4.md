- Fix: MacGlass kept showing "needs permission to record the screen" although Screen Recording was allowed. It no longer relies on the system's pre-check (which can be wrong) and simply tries to capture; the hint only appears when macOS really refuses.
- The app is now signed with a stable identity (its bundle identifier), so the Screen Recording permission survives future updates.

**Once after updating:** if the hint still appears, remove MacGlass in System Settings > Privacy & Security > Screen & System Audio Recording with "−", add it again with "+" and reopen MacGlass – or run `tccutil reset ScreenCapture io.github.lumen-tools.MacGlass` and allow it again.
