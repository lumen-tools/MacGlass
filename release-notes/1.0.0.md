MacGlass 1.0 – RetroArch slang shaders over any Mac window or the whole desktop.

The app is the same as 0.1.10; this release marks MacGlass as stable.

- Glass (desktop and window overlay) and Clone modes, click-through, fullscreen
- Shader browser with RetroArch (libretro slang-shaders), Retro_Crisis and Imported; Import custom... and Recent imports
- Bilinear Filter, Pixel Size (incl. Custom... with two decimals), Scale, Aspect Ratio Correction, Flip, Orientation, Crop, FPS
- Shader parameters, profiles, global hotkeys, snapshots
- Universal app (Apple Silicon + Intel), macOS 13 or newer

The app is not notarized: see the README for the one-time `xattr` command.

MacGlass is an independent, unofficial project modelled on ShaderGlass by mausimus and is not affiliated with it.
