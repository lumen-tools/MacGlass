First release of MacGlass – RetroArch slang shaders over any Mac window or the whole desktop.

- Glass (desktop overlay, window overlay) and Clone modes, click-through, fullscreen
- Shader browser with RetroArch (libretro slang-shaders), Retro_Crisis (newest GDV-NTSC release) and Custom_Shader; `shaders_slang/...` paths resolve against the bundled libretro shaders
- Bilinear Filter (from ShaderGlass-Bilinear), Pixel Size, Scale, Aspect Ratio Correction, Flip, Orientation, Crop, FPS
- Shader parameters, profiles, global hotkeys, snapshots
- Universal app (Apple Silicon + Intel), macOS 13 or newer

The app is not notarized: see the README for the one-time `xattr` command.
